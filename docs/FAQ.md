# ❓ 常见问题（FAQ）

## 导入相关

### Q: 导入时提示「跳过 N 条」是什么原因？

系统会自动去重：同一个平台下相同订单编号的数据不会重复导入。再次导入同一份 CSV 时，已有记录会被自动跳过。

### Q: 支持哪些平台的订单导入？

目前支持**京东、淘宝/天猫、Steam、微信**四大平台批量导入，更多平台正在陆续接入：

其他平台（如美团、得物等）可以通过「手动添加」功能逐条录入。

### Q: 为什么导入后有些订单没有出现？

导入时会自动过滤以下订单：
- **京东/淘宝**：未完成状态的订单（待付款、已取消等）
- **Steam**：退款记录、钱包充值（总金额 ≤ 0 的记录）
- **微信**：收入 / 不计收支等非支出流水；退款或异常状态（已全额退款、已退款(¥X)、对方已退还 等）；金额 ≤ 0 或重复交易单号的记录
- **全部平台**：已存在的重复订单

> 💡 微信转账、红包、扫码付款、群收款等**非购物流水会保留入库**（商品名回退为交易对方），以便看到日常支出全貌。

### Q: 京东/淘宝用微信/支付宝支付的订单会重复记账吗？

**不会了**。日耗仓除了按平台去重（京东按「订单编号」、微信/支付宝按「交易单号」），还支持**跨平台自动去重**：微信可以支付淘宝/京东、支付宝可以支付淘宝，同一笔消费会同时出现在平台订单 CSV 与支付账单中。系统会把「账单商家单号以平台订单号为后缀 且 金额一致」的记录判定为同一笔消费并自动跳过，导入结果会提示「跨平台重复 N 条」。**先导平台订单或先导账单都不会重复记账**，但**推荐先导平台订单（京东 / 淘宝 CSV）、再导微信 / 支付宝账单**——去重会保留先导入的记录，而平台 CSV 含商品链接、编号等更全信息；实测约 1/4 的支付宝支出（淘宝订单）可借此补全商品信息，其余为交通 / 餐饮等日常流水，账单是唯一来源。

**建议**：以平台自身导出的订单为准，微信 / 支付宝账单用于补充日常支出。

### Q: 京东导出时被风控怎么办？

建议按年份分段导出，而不是一次性导出全部历史。例如：先导出 2024 年，完成后再导出 2025 年。

### Q: 淘宝导出的 CSV 文件在哪里？

导出完成后 Chrome 会自动下载到系统的「下载」文件夹。文件命名格式为 `tb-orders-YYYYMMDD-HHmmss-complete.csv`。

### Q: 能不能导入 Excel 文件？

支持 **CSV** 和 **Excel（.xlsx）** 两种格式。微信账单可直接导出 Excel 文件导入；其他 Excel 文件同样支持直接导入（如个别文件解析异常，可先用 Excel/WPS 另存为 CSV 再导入）。

### Q: 导入后可以修改数据吗？

可以。点击任意物品卡片进入详情浮窗，点击「编辑」即可修改任意字段。

## 日均成本相关

### Q: 日均成本是怎么计算的？

- **使用中的物品**：日均成本 = 购买价格 ÷ 从购买日到今天的天数
- **已售出的物品**：日均成本 = (购买价 - 卖出价) ÷ 持有天数
- **已报废的物品**：日均成本 = 购买价 ÷ 持有天数

### Q: 0 元赠品的日均成本是多少？

0 元赠品的日均成本直接为 0，不参与日均成本排序。

### Q: 修改了物品的购买日期，日均成本会更新吗？

会。日均成本是每次查询时动态计算的，修改购买日期后自动更新。

### Q: 为什么日均成本等于购买价格？

这通常是因为购买日期是今天或昨天，持有天数只有 1 天，所以日均成本 = 购买价格。随着持有天数增加，日均成本会逐渐下降。

## 数据管理相关

### Q: 数据存储在哪里？

| 平台 | 存储位置 |
|------|----------|
| Windows 桌面端 | `AppData/com.bunnychen.dailycostvault/bookkeeping.db` |
| Android | 应用私有目录的 SQLite 数据库 |
| 网页版 | 浏览器 localStorage |

### Q: 数据会丢失吗？

- **桌面端/Android**：数据存储在 SQLite 数据库中，不会因关闭应用而丢失
- **网页版**：数据存储在浏览器中，清除浏览器缓存/数据会导致丢失。建议定期导出备份

### Q: 如何迁移数据到新设备？

1. 在旧设备上进入设置页，点击「导出数据库」
2. 将导出的 `.db` 文件传输到新设备
3. 在新设备上进入设置页，点击「导入数据库」选择该文件

### Q: 导入数据库后原来的数据还在吗？

导入数据库会**替换**当前所有数据。建议先导出当前数据作为备份。

### Q: 能不能多设备同步数据？

目前不支持云端同步。你可以在不同设备间通过导出/导入数据库来手动同步。

### Q: 清除所有数据后能恢复吗？

不能。「清除所有数据」操作不可撤销，操作前请务必先导出备份。

## 使用相关

### Q: 物品太多，怎么快速找到某一件？

- 使用主页顶部的搜索框，支持按物品名称、店铺名称、型号、订单号模糊搜索
- 使用平台筛选下拉框，只显示某个平台的物品
- 按日均成本降序排列，快速定位「烧钱」最多的物品

### Q: 不想删除但仍想从主页隐藏某件物品？

使用「归档」功能。在物品详情浮窗点击「📦」按钮，物品将从主页隐藏但数据保留。归档物品可在设置页的归档管理中查看和恢复。

### Q: 已归档的物品如何恢复？

进入设置页 → 归档管理区域 → 找到要恢复的物品 → 点击「📥」按钮。

### Q: 如何永久删除物品？

物品需要先归档，然后才能永久删除。归档后，在物品详情浮窗点击「🗑️」按钮，确认后不可恢复。

### Q: 应用有广告吗？

没有。日耗仓在 Beta 阶段完全免费，不包含任何广告。

### Q: 支持深色模式吗？

支持。设置页可切换浅色 / 深色 / 跟随系统三种主题模式。还可以切换 5 套配色方案（抹茶绿/天之蓝/莓之紫/桃之粉/橘之橙）。

### Q: 能不能给不同平台设置不同颜色？

可以。在设置页中每个平台旁边有一个色点按钮，点击弹出颜色选择器，可以从 10 种预设颜色中选择或输入自定义 HEX 颜色值，即时生效。

### Q: 自定义表情是什么？怎么用？

日耗仓内置 37 个自定义表情，分 4 大分类：Party Parrots（15 个鹦鹉 GIF 动画）、Reactions（12 个 Blob 风格 SVG）、Cats（6 个猫咪 GIF）、Mascots（4 个 GitHub 风格图标）。在手动添加或编辑物品时，点击图标选择器即可挑选。

### Q: 搜索无结果怎么办？

当搜索或筛选无结果时，页面会显示引导提示：区分「纯关键词搜索」「纯平台筛选」「两者叠加」三种场景，并提供「清除所有筛选」按钮一键恢复。

### Q: 物品已售出怎么记录？

编辑物品时展开「可选信息」区域 → 使用状态选择「已售出」→ 设置截止日期和售出价格。系统自动计算实际净成本和盈亏（盈利时显示为绿色）。

### Q: 0 元赠品的日均成本怎么算？

0 元赠品（价格 = 0）的日均成本直接为 0，不参与排序对比。这类物品主要用于资产记录而非成本追踪。

### Q: 客户端闪退 / 报错，怎么查看日志文件？

日耗仓会在本地保存运行日志（自 2026-08 版本起启用），排查闪退、报错或异常行为时非常有用。

**日志文件位置与快速打开方式**（桌面端也可在 **设置 → 备份与恢复 → 日志位置** 一键打开所在文件夹）：

| 平台 | 日志文件 | 快速打开 |
|------|----------|----------|
| Windows | `%LocalAppData%\com.bunnychen.dailycostvault\logs\logs.log`（例如 `C:\Users\你的用户名\AppData\Local\com.bunnychen.dailycostvault\logs\logs.log`） | 按 `Win + R`，粘贴 `%LocalAppData%\com.bunnychen.dailycostvault\logs` 后回车 |
| macOS | `~/Library/Logs/com.bunnychen.dailycostvault/logs.log`（例如 `/Users/你的用户名/Library/Logs/com.bunnychen.dailycostvault/logs.log`） | Finder → 按 `Cmd + Shift + G` → 粘贴 `~/Library/Logs/com.bunnychen.dailycostvault` 后回车 |
| Linux | `~/.local/share/com.bunnychen.dailycostvault/logs/logs.log` | 文件管理器地址栏粘贴 `~/.local/share/com.bunnychen.dailycostvault/logs` 后回车 |
| Android | 使用 `adb logcat` 查看（启动 / 闪退信息在 logcat 中） | 供开发者使用 |

**说明**：

- 日志文件名为固定的 `logs.log`（不是按天轮转）。当日志超过约 500KB 时旧内容会被覆盖重写，因此排查前请先复现问题
- 日志只在**有输出时写入**：如 CSV 导入、运行时错误、未捕获的 JS 异常、Rust 崩溃（panic）等；日常浏览 / 记账不产生日志时文件可能为空
- 同时包含后端错误（如 CSV 解析失败）与界面运行错误（如加载异常）
- 排查建议：复现问题 → 退出应用 → 将 `logs.log` 反馈给开发者，可快速定位原因

> 💡 日志仅保存在本机，不会上传到任何服务器，隐私安全。

## 平台相关

### Q: 支持 macOS 吗？

支持。前往 **[🚀 安装与启动](getting-started.md)** 下载对应芯片的 `.dmg` 安装包（Apple M 系列 / Intel）。

### Q: 支持 iOS 吗？

iOS 版本正在规划中。目前可以使用网页版。

### Q: 支持 Linux 吗？

支持。前往 **[🚀 安装与启动](getting-started.md)** 下载 `.deb` 或 `.AppImage` 安装包。

### Q: 网页版和桌面版有什么区别？

| 区别 | 桌面版 | 网页版 |
|------|:---:|:---:|
| 数据存储 | SQLite | localStorage |
| 自动更新 | ✅ | — |
| 文件系统访问 | ✅ | 有限 |
| 离线使用 | ✅ | 需要先加载页面 |

### Q: Android 安装提示「解析包错误」？

确保下载的 `.apk` 文件完整（没有被截断），且 Android 系统版本 ≥ 8.0。

## 安全相关

### Q: 我的订单数据安全吗？

日耗仓完全离线运行，所有数据存储在本地，不会上传到任何服务器。详见 [PRIVACY](PRIVACY.md)。

### Q: 浏览器扩展会泄露我的购物数据吗？

不会。浏览器扩展仅在你本机 Chrome 中运行，不上传数据到第三方。导出完成后可以随时移除扩展。

### Q: 导出 CSV 文件中包含个人信息怎么办？

- 京东/淘宝扩展默认启用「脱敏」选项，收件人姓名、电话、地址会被部分隐藏
- 导出时可以不勾选「脱敏」获取完整信息，但请妥善保管导出的文件
- 不要将 CSV 文件提交到 GitHub 或发送给不可信的人
