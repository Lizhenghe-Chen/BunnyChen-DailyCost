# 🔒 隐私说明（Privacy Policy）

> 最后更新：2026 年 8 月 · 当前阶段：公开 Beta 测试

日耗仓（DailyCost Vault）是一款**完全离线运行**的个人资产数字化管理工具，目前处于公开测试阶段。[BunnyChen](https://github.com/Lizhenghe-Chen) 高度重视你的隐私和数据安全。

---

## 数据收集

### BunnyChen 不收集什么

日耗仓**不会**收集、上传或分享以下任何信息：

- ❌ 你的订单数据（商品名称、价格、购买时间等）
- ❌ 你的个人信息（姓名、地址、电话等）
- ❌ 你的设备信息
- ❌ 你的使用习惯或行为数据
- ❌ 任何形式的遥测或诊断数据

### BunnyChen 没有

- ❌ 用户账户系统
- ❌ 云同步服务
- ❌ 消费数据追踪（网页版仅使用 Google Analytics 做匿名访问统计，不收集订单 / 消费数据；桌面端与 Android 端完全离线，不加载任何分析脚本）
- ❌ 第三方 SDK
- ❌ 广告系统
- ❌ 崩溃报告自动上传

## 数据存储

所有数据**仅存储在你的本地设备**上：

| 平台 | 存储方式 | 路径 |
|------|----------|------|
| Windows | SQLite 数据库 | `%AppData%/com.bunnychen.dailycostvault/bookkeeping.db` |
| macOS | SQLite 数据库 | 应用数据目录（设置页可查看完整路径） |
| Linux | SQLite 数据库 | 应用数据目录（设置页可查看完整路径） |
| Android | SQLite 数据库 | 应用私有目录 |
| 网页版 | 浏览器 localStorage | 浏览器本地存储 |

数据**不会**自动同步到任何云端服务器。你可以通过应用内的「导出数据库」功能手动备份数据。

---

## 数据导出与备份

日耗仓提供以下数据导出功能：

- **导出数据库（.db）**：将 SQLite 数据库文件导出到你指定的位置
- **导入数据库**：从备份文件恢复数据

> ⚠️ 导出的 `.db` 文件包含你的所有物品数据。请妥善保管，不要分享给不可信的人或上传到公共仓库。

## 浏览器扩展隐私

日耗仓为京东、淘宝、Steam 提供了浏览器扩展用于导出订单数据；微信账单则无需扩展，直接在应用内导入。这些扩展同样遵循严格的隐私原则：

### 数据访问范围

每个扩展仅能访问其声明的特定域名：

| 扩展 | 可访问域名 |
|------|-----------|
| JD Order Exporter | `order.jd.com`、`details.jd.com`、`details.yiyaojd.com` |
| TB Order Exporter | `buyertrade.taobao.com`、`trade.taobao.com`、`trade.tmall.com` |
| Steam Order Exporter | `store.steampowered.com` |

### 数据不会上传

- 扩展**不会**将订单数据上传到任何远程服务器
- 扩展**不会**读取浏览器 cookie、密码或其他站点数据
- 扩展**不会**使用 `chrome.storage`、`localStorage`、IndexedDB 等持久化存储
- 扩展**不包含**任何分析、遥测或第三方 API 调用

### 敏感数据处理

- 收件人姓名、地址、电话号码**默认脱敏**（部分字符替换为 `*`）
- 用户可在扩展弹窗中取消脱敏选项
- 导出的 CSV 文件会对可能被表格软件当作公式执行的单元格加前缀，降低 CSV 公式注入风险

## 网络安全

### 应用网络活动

日耗仓仅在以下场景产生网络请求：

| 场景 | 说明 |
|------|------|
| 检查更新 | 访问 GitHub API 查询是否有新版本发布 |
| 下载更新 | 桌面端自动更新功能下载新版本安装包 |
| 网页版访问统计 | 网页版加载 Google Analytics 统计页面访问量（匿名、不涉及订单 / 消费数据）；桌面端与 Android 端不加载 |

订单与消费数据**不会**在任何网络请求中发送。网页版统计仅包含页面访问等匿名信息。

### 网页版

如果你使用网页版（`bunnychen.top`），页面通过 HTTPS 加密传输，但请注意：

- 所有数据存储在浏览器本地
- 清除浏览器缓存/数据会导致数据丢失
- 建议定期导出备份
