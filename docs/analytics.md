# 📊 数据分析

切换到底部导航栏的「📊 分析」页，直观洞察你的消费结构与长期趋势。

![数据分析 · 抹茶绿深色](assets/桌面端%20数据分析页面%20深色模式%20抹茶绿.jpg){ loading=lazy }

---

## KPI 概览

页面顶部四张 KPI 卡片，一眼尽览你的资产全局：

| 指标 | 说明 |
|------|------|
| 💰 总资产价值 | 所有「使用中」物品的购买总价 |
| 📅 日均消耗 | 当日所有在库物品的日均成本之和 |
| 📦 在库物品 | 当前使用中的物品数量 |
| ♻️ 已回收总额 | 已售出物品的回收金额合计 |

---

## 月度消费趋势

月度消费图表帮助你了解消费节奏：

- 支持按**平台**和**时间范围**筛选
- **柱状图**为主，可叠加**累计消费折线**对比
- 颜色梯度随值增高而饱和，峰值暖橙高亮

> 💡 **下钻查看**：点击柱状图中某个月份的柱子，可展开该月的消费明细面板；再点击具体商品即可跳转详情弹窗。

---

## 平台与分类占比

平台消费占比与分类占比**双饼图**，清晰呈现你的钱都花在了哪些平台和品类：

- 饼图颜色自动跟随当前主题配色
- 图例置于图表外部，确保图表清晰可辨
- 移动端自动纵向堆叠布局
