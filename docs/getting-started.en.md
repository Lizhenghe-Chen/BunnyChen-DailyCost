# 🚀 Installation

DailyCost Vault supports Windows desktop, Android, and Web — choose the platform that works best for you.

---

## Windows Desktop

The desktop version offers the most complete experience: local SQLite database, auto-update, drag-and-drop CSV import, and more.

1. Go to the [Releases](https://github.com/Lizhenghe-Chen/BunnyChen-DailyCost/releases) page
2. Download `DailyCost Vault_*_x64-setup.exe` (recommended) or `.msi` installer
3. Double-click to run the installer and follow the wizard
4. Launch "DailyCost Vault" from the Start Menu or desktop shortcut

> 💡 **SmartScreen Warning**: Windows may show a SmartScreen warning on first run. Click "More info" → "Run anyway" to proceed.

!!! tip "Desktop Recommended"
    Desktop version stores data in a local SQLite database, supports auto-update, drag-and-drop CSV import, and quick file manager access to the database — the best overall experience.

---

## Android

1. Go to the [Releases](https://github.com/Lizhenghe-Chen/BunnyChen-DailyCost/releases) page
2. Download the `.apk` file
3. Open the downloaded file — system will prompt "Install unknown apps"
4. Go to "Settings" → allow installation from this source
5. Return to the installation screen to complete

> 💡 It's recommended to disable "Unknown sources" permission after installation.

---

## Web Version

Visit [bunnychen.top/BunnyChen-Item-Bookkeeping](https://bunnychen.top/BunnyChen-Item-Bookkeeping/) directly — no installation needed.

> ⚠️ Web version data is stored in browser local storage. Clearing browser cache/data will cause data loss — please export backups regularly.

| Comparison | Desktop | Web |
|------------|:-------:|:---:|
| Data Storage | SQLite local database | Browser localStorage |
| Auto-update | ✅ Built-in | — |
| Drag-drop CSV import | ✅ | ✅ |
| Offline use | ✅ | Requires page loaded first |
| Data persistence | High | Lost on cache clear |
