# 📤 分享与报告

把资产账本做成一张可以分享的长图，或者生成你的**年度消费报告**——一键保存，晒到小红书、即刻、朋友圈都合适。

---

## 资产墙

**入口**：顶部导航栏 **📤** 按钮，或设置页「分享与报告」→「生成资产墙」。

资产墙海报包含：

- 📊 顶部统计：**物品数 / 总价值 / 日均成本**
- 🏷️ 你的**最爱品类**
- 🧩 按日均成本排序的前 12 件物品（emoji + 名称 + 日均成本）

![资产墙示例](assets/首页%20装备墙%20数码装备库.jpg){ loading=lazy }

!!! tip "小技巧"
    弹窗内先以**网页组件**形式预览海报（清晰可滚动），点「保存图片」才生成 **1080×2240 PNG 长图（3:4 竖版）**，非常适合小红书、即刻、朋友圈等平台。

---

## 年度消费报告

**入口**：分析页顶部的「📊 年度报告」按钮，或设置页「分享与报告」→「年度消费报告」。

年度报告包含：

- 💰 **年度总支出 / 日均支出 / 购买件数**
- 🏆 **最贵单品 Top 3**
- 📊 **平台分布**条形图

!!! info "按年份生成"
    分析页的「时间范围」若选中了某一年，报告就按该年生成；否则默认使用当前年份。

---

## 保存与分享

预览默认是**网页组件**（不是图片），确认效果后点击「保存图片」，才会渲染成 PNG：

- 🖥️ **桌面端**：点击「保存图片」→ 系统保存对话框选择位置
- 🌐 **网页版**：点击「保存图片」→ 直接下载 PNG

生成的长图**完全在本地绘制，不会上传任何数据**——这与日耗仓"批量入仓，由你掌控"的承诺完全一致。
