    🚀 安装与启动¶

    日耗仓（DailyCost Vault）支持 Windows、macOS、Linux、Android 和网页版五种使用方式，选择最适合你的平台开始使用。

    📥 下载与安装¶

    推荐使用路径：桌面端为主，移动端为辅

    京东 / 淘宝 / Steam 订单用浏览器扩展导出 CSV，微信账单直接在微信 App 内导出（无需扩展），所以推荐先在桌面端完成导入；之后再通过「导出数据库」把存档迁移到 Android 端随身查看。桌面端数据存本地 SQLite，支持自动更新、拖拽导入 CSV / Excel、快速定位数据库，体验最佳。

    🖥️ 桌面端导入订单 → 📤 导出数据库 .db → 📱 Android 端导入查看

    网页版¶

    直接访问 bunnychen.top/BunnyChen-Item-Bookkeeping，无需安装。

    ⚠️ 网页版数据存储在浏览器本地。清除浏览器缓存/数据会导致数据丢失，请定期导出备份。

    对比桌面版网页版
    数据存储SQLite 本地数据库浏览器 localStorage
    自动更新✅ 内置—
    拖拽导入 CSV / Excel✅✅
    离线使用✅需先加载页面
    数据持久性高清除缓存会丢失

    🔒 安全说明¶

    • 所有文件均托管于官方 GitHub Release，未做任何修改。
    • 桌面端自动更新走 Tauri Updater，会校验 minisign 签名。
    • 手动下载的安装包可配合对应的 .sig 文件用 minisign 校验。
